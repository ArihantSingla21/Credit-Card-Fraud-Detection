!THRESHOLD

The 10,000 filter changes the population

The notebook drops every row with Amount ≥ 10,000. High-value legitimate cases are not automatically noise; report their count and justify exclusions before training.

POTENTIAL SELECTION BIAS
!TIME FEATURE

“Time” is elapsed time, not clock time

Time_hour is derived modulo 24 from seconds since the first record. The dataset spans two days, so that transformation merges both days’ same-hour activity.

INTERPRETATION LIMIT

Balancing can help reveal patterns visually, but correlations calculated on an undersample need not represent the original transaction population.

A1

Fit preprocessing inside each training fold

RobustScaler is fitted before the train/test split in this notebook. Fit it on training data only, ideally within a scikit-learn Pipeline, to avoid information leakage.

A2

Keep the natural class ratio out of training resampling

Undersampling should happen only within training folds. Preserve an untouched, representative test set for estimating real-world precision, recall, and alert volume.

A3

Use scores for ROC-AUC and stratify splits

Use predict_proba or decision_function for ROC-AUC, and use stratified splits so the rare positive class is represented consistently.
